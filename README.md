# Little Forecast

A small React weather app for looking up the current weather in a city. It shows
temperature, humidity, feels-like temperature, wind speed, and a simple
weather description.

## Run it

1. Install dependencies with `npm install`.
2. Start the app with `npm start`.
3. Search for a city or pick one of the suggested cities.

## Weather API

The app uses the free [Open-Meteo API](https://open-meteo.com/) to find cities
and retrieve current weather. No API key is needed. An internet connection is
required.
